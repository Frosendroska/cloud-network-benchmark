# Campaign data model

- **OperatorSettings**: schema version; repository/state/results paths; shared budget scope and ledger path; provider IDs/images/controller CIDR/SSH references; actual dated price/approval sources; stage starts/common-N/window inputs; optional backup destination and notification command. Missing real values are errors, never filled from fixtures. Secret files remain outside export.
- **StagePlan**: stage identifier in acceptance/calibration/day/week; existing config references; registered entry IDs; settings reference. WEEK resolves exactly 56 rows and no P2/P3/replacement.
- **PreparedStage**: stable controller_session_id, frozen source hashes, shared ledger path/scope, all entries and exact UTC slots. Written before launch, reusable without reinitializing IDs.
- **PreparedEntry**: entry_id; config_path; schedule_path and row_id where applicable; scheduled_start; launch_at; runtime_config_path; common cost_inputs_path; parent_manifest_path; run_ids; unique private_root. Existing parent/child contracts remain authoritative identities.
- **JournalEntry**: prepared entry plus state `scheduled|starting|running|complete|failed|missed`, subprocess identity/launch time, latest lifecycle result, cleanup liabilities and evidence paths. Transition scheduled→starting is durably saved before spawn; starting→running cannot erase launch uncertainty; terminal status requires existing files/validation/cleanup evidence. Missed entries are never backfilled.
- **StageJournal**: schema_version, frozen prepared stage, per-entry states, timestamps, output paths and peak disk/memory. Atomic replacement and directory fsync; one exclusive driver lock; journal and recovery private.
- **Export**: public manifests, native raw directories, descriptor copies with relocation provenance, selection version 1, summary and SHA-256 seal. Native file bytes stay unchanged. No credentials, Terraform state, runtime or recovery journals. Backup copies only closed verified exports.
