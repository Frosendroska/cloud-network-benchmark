# F07 data model

Reuse existing F01R models; consume GCP STOP only after coordinator-owned F01R_GCP_EXPIRY merges. No new shared DTO/schema.

| Entity | Required constraints and relationships |
| --- | --- |
| ProviderDeploymentInput | provider=gcp; schema_version=2; run_id=campaign_id+"-gcp"; deployment_id=run_id+"-deployment"; exactly vm_a client and vm_b receiver; existing V2 mode/scenario invariants; provider_options STANDARD/STOP after prerequisite |
| ReservationEvidence | state=reserved; observed ID, nonnegative finite reserved cost, original cap_started_at/expires_at/cap_start_policy_id; source path/hash; dated identified complete-workflow cost including compute/disk/IP/transfer/support/tax/uncertainty; no cleanup blocker |
| ExpiryRequest | action=stop; exact provider/run/deployment/reservation; resource_namespace matches private attempt; target_selector identifies project and both intended role names/zones before registration, resolved to template unique IDs through journal; expires_at=T=reserved end minus 30 seconds |
| ExpiryEvidence | existing not_registered/registered/failed/cancelled/triggered states; registered requires both observed template registrations, registration UTC after cap start and before pair creation, expires_at=T; provider_metadata contains role->template numeric ID/unique self link/creation time/properties hash, expected scheduling, cap endpoint, policy ID, cost-source identity and readback time; failed carries FailureEvidence |
| GcpRuntimeSettings (private local model) | exact project ID/identity reference; role->exact ubuntu-os-cloud image identities; controller IPv4 /32; attempt public SSH key and private key/known_hosts references; private attempt root; positive finite complete_workflow_remaining_seconds and sourced estimate reference; supplied review StructuredEvidence with decision=approved/scenario/source_path/source_sha256/reviewed_at when S2/S4 require admission; command timeout bounds; dated support cost fixture identity/hash; secrets excluded |
| Attempt journal (private local file) | full run/deployment/provider/project ownership; canonical per-role name/zone/private IP; namespace hash; original reservation/cap/T; protection/pair paths; observed operation IDs/template IDs/hashes; actual binding request/config hash; known VM numeric IDs/disks/public IPs/support resources; creation-may-have-started flag; redacted failures and complete/partial inventory; atomic writes and restricted permissions |
| ProviderVmOutput | exactly one each role; observed resource_id/image/shape/private IPv4/region/zone; public_ipv4 evidence; placement metadata includes requested and observed compact policy plus no maxDistance; physical_zone_id unavailable unless genuinely exposed; connection only with authenticated known_hosts or explicit partial/unavailable evidence |
| ProviderDeploymentOutput | existing identities/mode/provider/scenario, apply_action_id, UTC started_at/finished_at with registration <= started_at, both roles, provider_metadata/documented_network_limit; output_artifact_path=terraform-outputs.redacted.json; raw state is never this artifact |
| GcpCleanupResult (F07-owned) | cleanup_state uses existing CleanupState enum; primary_failure and cleanup_failure are optional separate FailureEvidence; inventory is StructuredEvidence; expiry is Evidence[ExpiryEvidence]; unknown/residual inventory requires failed/open state and failure; succeeded requires all resources absent plus protection removal/cancellation |

Namespace: deterministic provider-local safe name derived from full run/deployment identity, with a short digest to fit GCP name/label restrictions; private journal retains the exact source IDs. All create/read/delete operations bind exact project and observed IDs. Neither a short name prefix nor labels alone authorize deletion of an unrelated resource. Distinct attempt namespaces/VPCs permit fixed overlapping primary CIDRs across P0/P1.

Observed GCP JSON is kept provider-specific: instanceTemplates.get properties.scheduling; instances.get id, zone, machineType, scheduling, disks[].source, networkInterfaces and resourcePolicies; getGuestAttributes queryValue.items. Bind creation via actual sourceInstanceTemplate request/unique reference; do not invent an instance source-template response field. A STOP response/status is not full deletion.

Transitions: reserved/activated -> protection root operation completion -> both templates read back -> registered -> freshness/fit gate -> pair may have started -> observed complete/partial pair -> pair destroy -> verified compute absence -> protection deletion -> final absence -> cleanup succeeded/cancelled. Failure can occur at each transition. A registered-but-never-created attempt can delete unused protection safely after verifying no compute exists. Triggered requires observed provider termination evidence; reaching T locally proves only that expiry is due. Deleting templates while VMs exist cannot cancel inherited expiry. Unknown operations keep recovery and launch blocking open; repeated cleanup preserves original cap and ownership.
